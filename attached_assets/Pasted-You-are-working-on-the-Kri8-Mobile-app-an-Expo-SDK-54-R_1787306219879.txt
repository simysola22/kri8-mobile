`artifacts/kri8-mobile`

The APK currently launches correctly and Clerk initializes, but the **mobile authentication flow is broken**.

## CRITICAL AUTHENTICATION BUG

The current mobile app uses custom Kri8-branded Sign In and Sign Up screens.

The authentication is supposed to be powered entirely by **Clerk**, but the current Sign Up flow behaves incorrectly:

1. User opens Sign Up.
2. User enters their email/password.
3. Clerk sends the email verification code successfully.
4. User enters the verification code.
5. The Sign Up button spins briefly and stops.
6. No authenticated session is established.
7. Pressing Sign Up again produces "already verified".
8. User attempts Sign In.
9. Sign In reports that the account cannot be found / could not find your account.

This must be fixed properly.
