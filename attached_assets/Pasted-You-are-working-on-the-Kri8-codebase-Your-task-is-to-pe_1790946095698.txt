## 1. CRITICAL: Fix public profile data exposure

Audit:

`artifacts/api-server/src/routes/profile.ts`

The public profile endpoint currently serializes internal idea fields through the same serializer used internally.

Create a dedicated public serializer/DTO.

The public profile API must expose ONLY information intentionally designed to be public.

Do NOT expose internal/private fields such as:

* userId
* notes
* videoEditingNotes
* customDate
* usedDate
* parentIdeaId
* internal timestamps
* internal branch metadata
* database-specific/internal fields

Do not simply delete fields from the database model. Create a separate `serializePublicIdea()` so future additions to the internal idea schema cannot accidentally become public.

Audit recursive branches as well. Unless the existing product specification explicitly requires public branches, do not expose them from the public profile endpoint.

Preserve the existing public profile functionality.

## 6. Fix trend-data semantics

Audit the trend engine.

Never use `0` to mean "unknown".

For metrics such as growth percentage:

```ts
number | null
```

should be used when the value is unavailable.

For example:

* `35` = measured/calculated 35% growth
* `0` = measured zero growth
* `null` = growth unavailable

Apply the same principle to other metrics where appropriate.

Do not claim trend intelligence that the available data cannot support.

## 7. Improve trend scoring without inventing data

Audit the current trend scoring implementation.

Separate:

* measured data
* estimated data
* unavailable data

Do not manufacture engagement, velocity, growth, or popularity values.

Where enough real data exists, build a transparent weighted trend score using factors such as:

* recency
* engagement
* volume
* velocity
* cross-platform evidence

But only include a factor when the underlying data actually exists.

Document how the score is calculated.

## 8. Improve trend architecture for future historical data
